# Second coding (inter-coder reliability)

The East Asia, Southeast Asia and Countries of Origin pages say "Second coding: planned (Cohen's κ)". This folder holds the tools to do it.

1. `node build/second-coding/dump_codes.js` while `site/` is served on port 8765 writes the codes as visitors see them (after the official-text checks and recodes) to a JSON file. Edit the output path at the end of the script.
2. `python3 build/second-coding/make_worksheet.py CODES.json OUTDIR` draws a random sample (2 cells per worker group or country, seed 20261118; 54 cells on 18 November 2026) and writes `second-coding-worksheet.xlsx` for the second coder, with our codes hidden, plus `answer-key.csv`. Keep both outside this public repository. The 2026-11-18 copies are in the project files under `second-coding/`.
3. When the worksheet comes back: `python3 build/second-coding/kappa.py answer-key.csv returned.xlsx [site]` prints raw agreement, Cohen's κ and quadratic-weighted κ per page, writes `disagreements.csv` for discussion, and with `site` puts the result into the method table of the three pages. `southeast-asia/sea.js` is generated by `build/southeast-asia-build/build.py`, so rerun `kappa.py` with `site` after any rebuild.

Reading κ: 1 is perfect agreement, 0 is no better than chance, and above about 0.6 is usually read as good. The weighted version gives partial credit when the codes are one step apart (1 against 2).

## Second coding for the two data papers (20 November 2026)

`make_paper_sheets.py` extends the sample to the two Data in Brief papers: 44 of the 225 fully coded court decisions (about 20% per region; branch, outcome, follow-up, stages, arguments) and 131 of the 638 coded domestic-worker cells (about 20% per feature, spread across jurisdictions), plus the 54 comparison-page cells drawn on 18 November. Each item has one second coder (Felicia Nathania, Michelle Tjugito or Intan Nevia Cahyana), and about 20% also have a second person, so agreement between two people can be reported as well as agreement with IMR's codes. Seed 20261120.

    python3 build/second-coding/make_paper_sheets.py PAGES_WORKSHEET.xlsx PAGES_ANSWER_KEY.csv OUTDIR
    python3 build/second-coding/kappa_papers.py OUTDIR/keys RETURNED_DIR PAGES_ANSWER_KEY.csv
    python3 build/second-coding/kappa_papers.py --selftest

The answer keys (`OUTDIR/keys/`) stay out of this repository and away from the coders. Kappa per single feature rests on 2 to 7 cells, so report kappa per dataset and per court variable, and raw agreement per feature. The first coding was AI-assisted and edited by people; say so when reporting agreement with IMR's codes.
