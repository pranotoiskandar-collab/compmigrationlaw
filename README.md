# Comparative migration law

Court decisions and legal sources on migration, collected region by region for the Institute for Migrant Rights (theimr.org): its Court Decisions database and the Migration Law Atlas, including the farmworker view.

| Folder | Region |
|---|---|
| `east-asia/` | Hong Kong, Japan, South Korea, Macau, Mongolia, Taiwan (China noted) |

Each region folder uses the same columns as theimr.org's `court-decisions/data/decisions.csv`, so rows can move into the site's database as they are.
